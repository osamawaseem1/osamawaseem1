Working here as a Flutter developer since August 2024 — shipped a full UI redesign, built a more capable search experience, and optimised Firestore reads to cut database costs.

**Masajidna** — A mosque management platform I built independently. Three Flutter apps (admin, community member, and a mosque display screen) connected to a shared Firebase backend. The parts I'm most proud of: a "Catch Prayer" feature that uses Google Distance Matrix API to find mosques a user can actually reach before a prayer starts, and a data model change that reduced Firestore reads by 50% for display screens.
